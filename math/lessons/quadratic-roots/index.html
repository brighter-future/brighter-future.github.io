Solutions are the x-intercepts

Solving x squared - 2x - 3 = 0 means asking where the parabola y = x squared - 2x - 3 crosses the x-axis. Those crossing points are the roots.

You can also factor: x squared - 2x - 3 = (x - 3)(x + 1), so the roots are 3 and -1.

(x - p)(x - q) = 0 => x = p or x = q
